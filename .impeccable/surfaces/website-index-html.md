## Scope
Jessbot's public website (website/, built to _site/ by scripts/build-site.js): the landing page (Persuade), the user
guide rendered as pages (Read), a screenshot gallery. Audience: technical household owners deciding whether to self-host
an agent; they must believe it is useful and that it never acts without asking, then install it.

## Direction contract
THESIS: the page is built on the approval card. Its spine follows one real request (ask, background work, a card with
the exact text, Approve, sent) instead of the category's split hero over a row of identical feature cards.
OWN-WORLD: the app's own world: Harbor slate neutrals and one sea-teal accent, Geist, state colours only for state, and
Jess's living portrait in her sky (the scene picked from the visitor's clock: dawn, day, dusk, night) as the one
expressive material. Light and dark are both first-class.
STORY: the visitor meets Jess, sees a real card from a test run, presses Approve or Deny themselves, understands the
deal (it works on its own, it asks before it sends, spends or books), sees the rest of what it does in real screens,
reads what leaves their machine, and copies the install command.
FIRST VIEWPORT: a full-width band of Jess's sky; her round portrait large on the inline-start side; the name and a
one-line promise; the live approval card on the inline-end side, at real size, Approve/Deny working; under the promise,
the install command in a copyable field (the primary action) and a quieter GitHub link. Phones stack portrait, promise,
command, card.
FORM: structure 3 of 7 on the ranked list (the approval card as spine); seed: none (unavailable) — run unattended as a
subagent, no decision page served; the dealt lead was taken as assigned.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
